# Migrate agent-step 4.1.0 → 4.1.1

> Severity: **internal** — no export, signature or option changes. One model-facing sentence moves,
> and only for a tool that runs under required tool calling AND has a `repeatReadBack` gate.
> Applied by `/pull-library`; readable standalone.

## What changed

The required-mode protocol fragment (`composeProtocolPrompt`) carries one sentence about repeating
a question. 4.1.0 narrowed its field list; 4.1.1 restores the wording that was measured:

```text
4.1.0   …use `repeat_pending_question` when the pending record supplies stored text
        (a standing value ask's `ask_text` or `awaiting.question`, or a repeatable confirmation).

4.1.1   …use `repeat_pending_question` when the pending record supplies stored text
        (`ask_text`, `awaiting.question`, or a repeatable confirmation).
```

Nothing else in the library's behaviour changes. A tool in auto mode, and a required-mode tool with
no `repeatReadBack` gate (whose fragment never contains this sentence), compose byte-identical text
on 4.1.0 and 4.1.1.

## Why

The sentence maps a reply's CONTENT to a mechanism: the stored question and nothing else goes
through `repeat_pending_question`, whose result forbids added words; anything of the model's own
first is speech. With the narrowed field list, a channel check at a standing ask ("can you hear
me?") measurably left speech-with-reassurance for the repeat control, and the reassurance was lost.
Two further alternatives — reducing the sentence to a pointer at the reply contracts, and folding
ask repetition into speech — were measured too, and each moved other replies off the right
mechanism. The measurements are recorded beside the sentence in `compile/protocol.ts`.

**Known limit, accepted:** the sentence names `awaiting.question` without saying whose it is, so it
also matches the record of an ungated verbatim question, which the control refuses
(`repeat_confirmation_not_available`). The same caller turn then re-asks by speech — one extra
model round, nothing audible.

## Library replacement

The vendored `src/agent-step/*` is replaced wholesale by `/pull-library` (verbatim copy from the
toolkit). Changed files: `compile/protocol.ts` (the sentence and the comment beside it),
`protocol.test.ts` (the test pinning the narrowed wording is removed), `VERSION`. `npm test` then
runs 357 library tests.

A project upgrading straight from 4.0.0 applies `4.0.0-to-4.1.0.md` first and then this file; it
only ever composes the 4.1.1 wording.

## Manual follow-ups

- Do not reword this sentence in a host prompt, and do not add a prompt rule about WHEN to call
  `repeat_pending_question` beside it: the reply and ask contracts own that decision per reply, and
  a second voice is what the measurements above kept running into.
- A required-mode host that measured its live suites on 4.1.0 re-runs the cases that involve a
  standing ask: a channel check, a pause, and a claim about who is speaking.
